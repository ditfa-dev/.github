# Your workspace for AI

**Think clearly. Write with purpose. Build with AI.** Ditfa brings AI conversations, writing and code exploration into a workspace designed around your work.

[Explore Ditfa](https://ditfa.com) · [Open the workspace](https://chat.ditfa.com) · [Download the apps](https://ditfa.com/downloads)

## Build with Ditfa

| Project | What you'll find |
| --- | --- |
| [**Ditfa CLI**](https://github.com/ditfa-dev/ditfa-cli) | An open-source AI coding agent for your terminal, built in Rust. Work with supported hosted providers or local models, configure approvals and sandbox access, and connect tools with MCP. |
| [**Ditfa Downloads**](https://github.com/ditfa-dev/ditfa-releases) | Official desktop installers, release notes and update assets for macOS, Windows and Linux, with guidance for browser extension downloads. |

## Get started

- **Use the workspace:** start at [chat.ditfa.com](https://chat.ditfa.com).
- **Work from your terminal:** follow the [CLI quick start](https://github.com/ditfa-dev/ditfa-cli#start-your-first-task).
- **Install the desktop app:** choose your platform on the [downloads page](https://ditfa.com/downloads).
- **Explore ideas and guides:** read the [Ditfa journal](https://ditfa.com/blog).

## Open source and community

We welcome useful bug reports, focused improvements and thoughtful discussion. Read the [contribution guide](https://github.com/ditfa-dev/ditfa-cli/blob/main/CONTRIBUTING.md), ask a question in [CLI Discussions](https://github.com/ditfa-dev/ditfa-cli/discussions), or report a reproducible problem in the relevant repository.

For product or account help, [contact Ditfa](https://ditfa.com/contact). Report security vulnerabilities privately using the **Security** tab of the affected repository; see our [security policy](https://github.com/ditfa-dev/.github/blob/main/SECURITY.md).
